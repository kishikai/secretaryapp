# OCR accuracy evaluation

_Generated by `backend/eval/ocr_eval.py`; overwritten on every run._

## Method

The script renders 32 synthetic Messenger-like screenshots (390 px wide, seeded `random.Random(42)`, so the set is identical on every run): 16 light and 16 dark, and within each half 8 PNG and 8 JPEG at quality 75. Each has 3-6 rounded bubbles on random sides with English and Taglish sentences, 25% of bubbles have a blank line between paragraphs, and 7 screenshots have a centred grey timestamp. Every screenshot goes through the real `extract_messages` with one shared `PaddleEngine`. Ground truth is the text as rendered, so a soft word wrap counts as a `"\n"` (the pipeline cannot tell it from a hard newline). **This is synthetic data: clean fonts, uniform layouts and no avatars, reactions, link previews or emoji, so these numbers are an optimistic upper bound. Real Messenger screenshots are needed before trusting any threshold below.**
